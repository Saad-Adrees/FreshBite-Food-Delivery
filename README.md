# 🍔 FreshBite — Premium Food Delivery Website

FreshBite is a modern, responsive multi-page web application designed for a seamless online food ordering experience. Built with performance and user experience in mind, it features a clean layout, dynamic navigation, and essential customer features.

---

## ✨ Features

* **Responsive Design:** Optimized across mobile, tablet, and desktop viewports.
* **Interactive Navigation:** Smooth dynamic cart drawer and navigation elements.
* **Multi-Page Layout:** Includes pages for Home, Menu, About Us, Contact, Login, Signup, Privacy Policy, and Terms of Service.
* **Modern UI:** Clean typography, vibrant imagery, and sleek interactive call-to-action buttons.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Icons:** Font Awesome
